Тест фрагментов записи (только звук)

Автономная страница вне продукта ТОЛК — только браузерный MediaRecorder API, без Jitsi, без логина, без загрузки куда-либо. Нужна для проверки Этапа 3 (remux дорожки из отдельных фрагментов): реальный браузер режет запись на куски иначе, чем можно синтетически подделать через ffmpeg — нужны настоящие фрагменты из настоящего MediaRecorder.

Нажми «Начать запись», скажи что-нибудь вслух секунд 10-15 (или просто оставь звук в комнате — подойдёт любой звук, даже тишина), затем «Остановить». Появятся 3 файла для скачивания: отдельные фрагменты (chunk_000000.webm, chunk_000001.webm, ...) и один уже склеенный на стороне браузера файл (combined.webm). Пришли все файлы обратно в сессию — этого достаточно для проверки remux без доступа к прод-инфраструктуре.
